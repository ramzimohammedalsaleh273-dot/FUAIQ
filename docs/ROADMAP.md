# خارطة الطريق

## نُفذ في النسخة الحالية
- محرك Python تقليدي محلي: تصحيح اتجاه EXIF، تقليل تشويش اختياري، تباين، شحذ، وتكبير Lanczos.
- فحص أبعاد الصورة وحد البكسلات، حفظ منفصل، تحقق من ملف الناتج، وبيانات وصفية.
- واجهة أوامر واختبارات محرك الصور.
- API محلية اختيارية: فحص الصحة، رفع صورة ضمن حد حجم، معالجة، تنزيل النتيجة، ورفض الصيغ/المعرفات غير الصحيحة.
- واجهة هاتف عربية: اختيار صورة، معاينة الأصل/النتيجة، التحكم بالتباين والشحذ والتكبير، المعالجة في isolate منفصل، حفظ PNG في مستندات التطبيق ومشاركة الملف عبر النظام.
- سير عمل لاختبارات Python وAPI، وسير عمل مستقل لمحاولة بناء APK ونشره كأثر.

## غير مكتمل
- نموذج ذكاء اصطناعي متخصص ومختبر لإزالة الغباش واهتزاز اليد ورفع الدقة العصبي.
- التحقق من بناء APK وتشغيله على هاتف Android فعلي.
- حفظ مباشر إلى معرض الصور، وسجل عمليات/مشاريع قابل للإدارة.
- ربط واجهة الهاتف بمحرك Python؛ المعالجة في الهاتف مستقلة حاليًا.
- تحرير يدوي أوسع وخيارات مقارنة احترافية.
- خدمة سحابية إنتاجية آمنة، حسابات، حدود استخدام وموافقة وحذف؛ API الحالية للتطوير المحلي فقط.

## أولويات التنفيذ التالية
1. تشغيل واختبار Flutter وAPK على جهاز أو محاكي Android وإصلاح كل أخطاء البناء.
2. إضافة اختبارات تغطي صيغة الصور واتجاه EXIF والذاكرة والحالات الحدية على الهاتف.
3. تقييم نماذج الترميم وفق تراخيص الأوزان والبيانات ومقاييس جودة على صور اختبار مرخصة.
4. اختيار نموذج AI مناسب للأجهزة أو خدمة اختيارية، دون رفع الصور خفية أو افتراض استعادة تفاصيل مفقودة.
5. إضافة معرض نتائج/سجل ومشاركة وتصدير مباشر، ثم تقييم أمان أي خدمة سحابية قبل إطلاقها.
