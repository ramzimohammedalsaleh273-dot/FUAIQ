# تطبيق فائق للهاتف

واجهة عربية تعمل محليًا لاختيار صورة من المعرض، وعرض الأصل والنتيجة، وضبط التكبير، وتنفيذ معالجة تقليدية وحفظ PNG داخل مجلد مستندات التطبيق.

## التشغيل
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

النتيجة محفوظة داخل مجلد مستندات التطبيق؛ مشاركة الملف أو حفظه في معرض الصور لم يضاف بعد. لا يتضمن التطبيق نموذج AI متخصصًا حتى الآن.
