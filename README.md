# FUAIQ — فائق

مشروع مفتوح المصدر لتحسين الصور مع أولوية للحفاظ على الصورة الأصلية والشفافية بشأن ما تنفذه المعالجة. الإصدار الحالي يوفر محركًا محليًا قابلًا للتشغيل عبر سطر الأوامر وواجهة API اختيارية. لا يزعم هذا الإصدار وجود ترميم عصبي متخصص؛ نموذج الذكاء الاصطناعي لإزالة الغباش ورفع الدقة ليس مدمجًا بعد.

## الوظائف الحالية
- قراءة الصور الشائعة مع تصحيح اتجاه EXIF والتحقق من الصيغ.
- تحسين تقليدي اختياري: تقليل التشويش، ضبط التباين، الشحذ، والتكبير Lanczos ‏1×/2×/4×.
- عدم الكتابة فوق الصورة الأصلية.
- حد أقصى لحجم الصورة والتحقق من ملف الناتج.
- ملف JSON جانبي يوثق الإعدادات وخطوات المعالجة والقيود.
- واجهة أوامر، واختبارات آلية، وAPI محلية اختيارية.

## تشغيل Windows (PowerShell)
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
python -m unittest discover -s tests -v
```

## تحسين صورة
```powershell
fuaiq enhance "C:\Users\Public\Pictures\input.jpg" --output "C:\Users\Public\Pictures\input_fuaiq.png" --scale 2
```
يمكن أيضًا تشغيله دون تثبيت نقطة الدخول: `python -m fuaiq.cli enhance ...`.

## API محلية اختيارية
```powershell
pip install -e ".[api]"
uvicorn fuaiq.api:app --host 127.0.0.1 --port 8000
```
ثم افتح `http://127.0.0.1:8000/docs`. لا تعرض الخدمة للإنترنت العام دون مصادقة وحدود استخدام وحذف تلقائي للملفات.

## حدود الجودة
الطرق التقليدية لا تستعيد بالضرورة تفاصيل لم تسجلها الصورة، وقد ينتج عن الشحذ آثار جانبية. لا يوجد حاليًا نموذج متخصص لإزالة اهتزاز اليد أو ترميم الوجوه أو رفع الدقة العصبي. تطبيق الهاتف ما يزال هيكل واجهة أوليًا وغير موصول بمحرك المعالجة. راجع `docs/ROADMAP.md` و`docs/QUALITY_PLAN.md`.
