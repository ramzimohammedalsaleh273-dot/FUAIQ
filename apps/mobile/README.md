# تطبيق فائق للهاتف

واجهة عربية لمعالجة الصور محليًا: اختيار صورة من المعرض، معاينة الأصل والنتيجة، التحكم في التباين والشحذ والتكبير، حفظ النتيجة PNG في مستندات التطبيق، ومشاركة الناتج عبر قائمة المشاركة في النظام.

## التشغيل
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

المشاركة تستخدم قائمة مشاركة النظام؛ ومن خلالها يمكن اختيار تطبيق الصور أو الملفات إذا كان متاحًا. لم يُتحقق بعد من التشغيل على جهاز Android فعلي في بيئة التطوير هذه.

## حدود معلنة
المعالجة تقليدية ولا تستخدم نموذج AI متخصصًا لإزالة الغباش أو اهتزاز اليد أو رفع الدقة العصبي. لا توجد معالجة سحابية في الإصدار الحالي.
