# البنية الحالية

- `fuaiq/models.py`: خيارات المعالجة ونتيجتها.
- `fuaiq/engine.py`: تحميل آمن نسبيًا، معالجة تقليدية، حفظ الناتج والتحقق منه وكتابة بيانات وصفية.
- `fuaiq/cli.py`: واجهة أوامر.
- `fuaiq/api.py`: API اختيارية للتطوير المحلي.
- `tests/`: اختبارات وحدة.
- `apps/mobile/`: تطبيق Flutter أولي؛ تكامل الهاتف قيد العمل.

الهدف المعماري هو معالجة محلية أولًا، مع إبقاء أي معالجة سحابية مستقبلية اختيارية وبموافقة صريحة. لا توجد حاليًا قاعدة بيانات مستخدم أو نظام حسابات.
