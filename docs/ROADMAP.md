# خارطة الطريق

## متاح في النسخة الحالية
- محرك صور تقليدي محلي مع حفظ منفصل وتوثيق الإعدادات.
- سطر أوامر واختبارات آلية؛ API محلية اختيارية.

## غير مكتمل
- نموذج ذكاء اصطناعي متخصص لإزالة الغباش واهتزاز اليد ورفع الدقة.
- واجهة هاتف عملية لاختيار الصورة وعرض قبل/بعد وتوصيل المحرك.
- تحرير يدوي متقدم، تاريخ مشاريع، وتصدير ومشاركة من الهاتف.
- خدمة سحابية آمنة، حسابات، حدود استخدام، وإدارة خصوصية.

## أولويات التنفيذ
1. تثبيت واجهة اختيار صورة ومعالجة محلية في الهاتف.
2. مقارنة قبل/بعد وإعدادات واضحة مع الحفاظ على الأصل.
3. تقييم نماذج الترميم وفق تراخيصها وقياسات جودة وصور اختبار مرخصة.
4. دعم معالجة محلية/سحابية اختيارية مع موافقة صريحة وسياسة حذف.
