# الخصوصية

- محرك سطر الأوامر يعالج الملفات محليًا ولا يرسلها إلى أي خدمة.
- API اختيارية محلية للتطوير؛ الملفات المرفوعة تحفظ مؤقتًا أثناء المعالجة والنتائج تحفظ في مجلد الإخراج.
- لا تنشر API على الإنترنت العام دون مصادقة، وحدود طلبات، وتحديد مدة الاحتفاظ، وحذف النتائج، وسجل تدقيق لا يتضمن بيانات الصور.
- تجنب رفع صور خاصة أو حساسة إلى بيئات لا تتحكم بها.
- لا يرفع تطبيق الهاتف الصور إلى السحابة في الإصدار الحالي.
