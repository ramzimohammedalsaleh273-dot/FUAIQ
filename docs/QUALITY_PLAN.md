# خطة الجودة

- اختبارات وحدات للأبعاد، حفظ الأصل، رفض الصيغ غير المدعومة، وحدود البكسلات.
- اختبار ملفات صور متنوعة: JPEG وPNG وWebP واتجاه EXIF ومدخلات تالفة.
- قياس الجودة باستخدام بيانات اختبار مرخصة ومقاييس PSNR/SSIM عند توفر مرجع نظيف، مع تقييم بصري أعمى.
- فحص آثار الشحذ والضوضاء على صور الوجوه والنصوص والمناظر.
- عدم وصف التكبير التقليدي بأنه ذكاء اصطناعي أو وعد باستعادة تفاصيل غير موجودة.
